# Cherish · Week One Rhythm

A responsive, print-friendly infographic for the first-week rhythm described in Helen Moon's *Cherish the First Six Weeks*.

Open `index.html` in a browser. No build step or dependencies are required.

The public Week 1 summary gives a 2–3 hour feeding cadence rather than a fixed set of clock times. The five daytime cycles use a consistent illustrative 3-hour rhythm: 7–10, 10–1, 1–4, 4–7, and 7–10. The page explicitly notes that hunger cues and a baby's clinician-directed plan take priority.
