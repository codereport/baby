# Cherish · The First Six Weeks

A responsive, print-friendly infographic set covering Weeks 1–6 of Helen Moon's *Cherish the First Six Weeks*.

Open `index.html` in a browser and use the numbered week selector. No build step or dependencies are required. A week can also be linked directly with `?week=1` through `?week=6`.

The first weeks use a consistent visual rhythm. Later weeks add the book's more explicit nap, bath, bedtime, dream-feed, and overnight-feed targets. The page explicitly notes that hunger cues and a baby's clinician-directed plan take priority.
